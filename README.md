# PhoneBot website

Simple project page for PhoneBot.

Local preview: open `index.html` in a browser, or from this folder run:

```bash
python3 -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.

## GitHub Pages

After the files are on `main`, enable Pages in the GitHub repository:

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: `main`, folder: `/ (root)`
4. Save

The site URL will be:

`https://hruochenUCLA2021.github.io/PhoneBot-website/`
